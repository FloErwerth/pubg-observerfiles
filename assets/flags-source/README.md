# Originale der Flaggen

Diese PNGs sind die unveränderten Flaggen des Pakets vor der Optimierung für
Version 1.2.2. Die Herkunftshinweise in `../../THIRD_PARTY_NOTICES.md` gelten
weiterhin. Italien und Niederlande werden durch `scripts/generate-extra-flags.ps1`
gezeichnet.

`scripts/optimize-flags.ps1` erzeugt daraus die Paketdateien reproduzierbar:
sichtbare Alphagrenzen ermitteln, auf ein gemeinsames 3:2-Rechteck mit 192 × 128
Pixeln skalieren und moderat per Unscharfmaskierung nachschärfen. Nationale
Seitenverhältnisse werden bewusst angeglichen. Originale niemals durch die
optimierten Ergebnisse ersetzen, sonst würde wiederholtes Schärfen Artefakte
verstärken.
