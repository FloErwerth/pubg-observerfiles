# PUBG Observer Installer 1.1.0

**Flaggen ohne Nummern** ersetzt das bisherige Nummern-Paket. Die 23 urspruenglichen Bilder stammen aus `observerfiles-flags`. Ergaenzt wurden Team 24 (**Italien**) und Team 25 (**Niederlande**) mit neu erzeugten Flaggen ohne Nummern. Die CSV wurde entsprechend erweitert.

| Paket | Teamnummern mit eigenen Bildern |
| --- | --- |
| Flaggen mit Nummern (Standard) | 1-50 |
| Emojis | 1-100 |
| Flaggen ohne Nummern | 1-25 |

Der Installer zeigt die Abdeckung des gewaehlten Pakets jetzt direkt an. Alle CSV-Eintraege haben ein lesbares Bild; Teamnummern und Datei-Pruefsummen wurden geprueft.

## Installation / Update

1. `PUBG-Observer-Installer.exe` herunterladen und PUBG schliessen.
2. EXE starten, Paket auswaehlen und **Installieren** anklicken.
3. Vorhandene Observer-Dateien werden automatisch gesichert und ersetzt.

Das Herunterladen der neuen EXE allein veraendert die installierten Observer-Dateien nicht.

Windows mit .NET Framework 4.5 oder neuer erforderlich. Die EXE ist unsigniert; Windows kann einen unbekannten Herausgeber melden. `SHA256SUMS.txt` enthaelt die Download-Pruefsumme.

Die genaue Anzeige fuer Teamnummern ausserhalb eines Pakets wurde nicht im Spiel verifiziert. Ein Test innerhalb von PUBG steht aus. Quellen- und Lizenzstatus der Observer-Pakete siehe [THIRD_PARTY_NOTICES.md](https://github.com/FloErwerth/pubg-observerfiles/blob/master/THIRD_PARTY_NOTICES.md).
